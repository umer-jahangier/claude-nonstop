# Launch kit

Drafts for you to post yourself, in your own voice. Edit freely before posting.

| File | Where | When |
| --- | --- | --- |
| [show-hn.md](show-hn.md) | Hacker News, *Show HN* | Weekday, 8–10am US Eastern (5–7pm Lahore) |
| [reddit.md](reddit.md) | r/ClaudeAI and r/ClaudeCode | A few days apart; read each subreddit's rules first |
| [devto-article.md](devto-article.md) | dev.to (and Medium, with the canonical URL set to dev.to) | Any time; post it before the Reddit threads so they can link to it |
| [x-thread.md](x-thread.md) | X / Twitter, LinkedIn | Same day as Show HN |
| [awesome-lists.md](awesome-lists.md) | Curated lists | After the posts have brought some stars |
| [answers.md](answers.md) | Existing GitHub issues and threads | Only where it really answers the question |

**Ground rules that keep posts from being removed**
- Say in the first line that you made it.
- One post per community; don't cross-post the same text.
- Stay in the thread for the first two hours and answer every question.
- Be upfront about the terms caveat (using one company's subscription from another company's tool). People will ask, and an honest answer earns trust.
- Never ask for upvotes or stars, and never use other accounts to upvote.
