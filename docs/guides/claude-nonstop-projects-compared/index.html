The claude-nonstop projects compared

Several unrelated open-source projects are called claude-nonstop or something close. This site is about umer-jahangier/claude-nonstop by Muhammad Umer (Umer Jahangier): a cross-platform tool and local gateway that moves Claude Code, Codex and the Claude desktop app between your accounts and API keys. The others solve related problems in different ways.

At a glance

Projects named claude-nonstop and what each does
ProjectWhat it doesRuns on
umer-jahangier/claude-nonstopMoves Claude Code, Codex and the Claude desktop app to your next account, then your API keys, when a limit hits. Local gateway with mid-request key failover and Anthropic ↔ OpenAI translation. One-line installer, web page, self-updating. npm: @umer-jahangier/claude-nonstop.macOS, Windows, Linux
rchaz/claude-nonstopMulti-account switching for Claude Code, plus remote control of sessions through Slack channels. Published on npm as plain claude-nonstop.macOS (Linux untested, per its README)
Darkwing4/claude-nonstopKeeps one Claude Code session going through network drops, cut-off turns, overloads and limits by retrying and waiting, using the StopFailure hook. No account switching.Rust
orbenozio/claude-code-nonstopA VS Code extension that adds an on/off toggle to the Claude Code panel, pings Claude to continue, and resumes when the limit window reopens.VS Code
garetneda-gif/claude-nonstopStop hooks that keep a Claude Code agent from stopping mid-task to ask whether to continue.Python hooks

Descriptions are from each project's own README, checked on November 19, 2026. Each is maintained separately; check its repository for current details.

Which one do you need?

  • Several accounts or API keys, and you want work to move between them by itself, on any operating system, including Codex and the desktop app: umer-jahangier/claude-nonstop.
  • Remote control from Slack on a Mac: rchaz/claude-nonstop.
  • One account, and you only want to ride out errors and limit resets: Darkwing4/claude-nonstop or the VS Code extension.
  • An agent that stops to ask "should I continue?": garetneda-gif's stop hooks.

Questions

Who makes umer-jahangier/claude-nonstop?

Muhammad Umer (Umer Jahangier, @umer-jahangier on GitHub), an AI and full-stack engineer in Lahore, Pakistan. It's MIT licensed.

Is umer-jahangier/claude-nonstop the claude-nonstop package on npm?

No. The plain claude-nonstop package on npm is rchaz's project. umer-jahangier/claude-nonstop is published as @umer-jahangier/claude-nonstop, and its recommended install is the one-line installer.
